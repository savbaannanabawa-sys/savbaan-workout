Savbaan Workout Android project

This is an Android Studio project that wraps the offline Savbaan Workout tracker in a WebView.
The workout tracker is bundled in app/src/main/assets/index.html and is designed to work offline.

Build APK:
1. Install Android Studio on a computer.
2. Open this folder as a project.
3. Let Android Studio sync/download the Android Gradle Plugin and SDK components.
4. Choose Build > Build Bundle(s) / APK(s) > Build APK(s).
5. Install the generated APK from app/build/outputs/apk/debug/app-debug.apk on your Android phone.

No Android SDK/Gradle build environment is available in the current file-generation environment, so an installable APK has not been compiled here.
